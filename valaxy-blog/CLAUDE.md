成员清单
site.config.ts: 公开身份、社交链接、搜索与赞助配置。
valaxy.config.ts: 主题、插件与构建扩展入口。
package.json: 固定 Valaxy 版本，提供开发和构建命令。
pnpm-lock.yaml: 固定依赖解析结果。
tsconfig.json: TypeScript 编译与模块解析配置。
README.md: 博客目录与构建说明。
Dockerfile: 容器构建入口。
nginx.conf: 容器内静态站点服务配置。
netlify.toml: Netlify 构建配置。
vercel.json: Vercel 部署配置。
.dockerignore: 排除容器构建上下文中的本地文件。
.editorconfig: 文本缩进与换行约定。
.gitignore: 排除本地依赖与生成文件。
.npmrc: npm 与 pnpm 安装选项。
.github/: GitHub Pages 构建流程。
.valaxy/: 路由类型生成文件。
.vscode/: 编辑器工作区设置。
components/: 博客页脚与文章元信息组件。
layouts/: 布局扩展入口。
locales/: 中英文翻译。
pages/: 博客文章与站点页面。
public/: 随站点原样发布的图片与响应头。
styles/: 主题变量与样式覆盖。
